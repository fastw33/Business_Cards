# Material comercial Fastway

Coloca aquí los PDF que deban aparecer en el directorio. Se detectan automáticamente.
Usa nombres descriptivos en minúsculas, por ejemplo `servicios-internacionales.pdf`.
Una portada opcional debe tener el mismo nombre: `servicios-internacionales.webp`.

El catálogo inicial se puede reemplazar conservando `catalogo-fastway.pdf`.
Los títulos y detalles opcionales están en `src/pages/fastway.brochures.js`.
Para publicar los cambios, compila y despliega el proyecto.
