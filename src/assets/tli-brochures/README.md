# TLI brochures

Add TLI PDFs here. They appear automatically under **Brochures & resources** after the next build. Use an English filename such as `TLI-Company-Profile.pdf`; hyphens become spaces in the displayed title.

An optional WebP, PNG or JPG with the same basename becomes its cover. The section stays hidden until at least one PDF exists. This directory does not use any other company's brochures.
